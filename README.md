# Tula’s Crane API 

## Descripción

**Tula’s Crane API** es una interfaz de programación de aplicaciones desarrollada con **ASP.NET Core y .NET 8**, diseñada para gestionar y conectar los servicios digitales de Tula’s Crane, empresa especializada en la renta de grúas, maquinaria pesada y maniobras especializadas.

Esta API funciona como parte del sistema de gestión empresarial de Tula’s Crane, permitiendo la comunicación entre el frontend y la lógica del backend, así como la integración de funcionalidades de autenticación y administración.

## Objetivo del proyecto

Desarrollar una solución tecnológica que contribuya a la digitalización de los procesos operativos y administrativos de la empresa, facilitando la gestión de la información y sentando las bases para la integración de módulos empresariales.

## Tecnologías utilizadas

- **C#** — Lenguaje de programación.
- **ASP.NET Core (.NET 8)** — Desarrollo de la API.
- **SQL Server** — Tecnología prevista para la gestión de datos.
- **Swagger / OpenAPI** — Documentación y exploración de los endpoints.
- **HTML, CSS y JavaScript** — Interfaz web integrada en el proyecto.

## Funcionalidades principales

- Autenticación de usuarios mediante endpoints de la API.
- Comunicación entre el frontend y el backend.
- Integración con el sistema de administración empresarial.
- Configuración de CORS para permitir la comunicación entre aplicaciones.
- Documentación y pruebas de endpoints mediante Swagger.
- Servicio de archivos estáticos para la interfaz web.

## Contexto del proyecto

Este desarrollo forma parte del proyecto de digitalización de Tula’s Crane, orientado a mejorar la organización de la información y facilitar la administración de los recursos y servicios de la empresa.
